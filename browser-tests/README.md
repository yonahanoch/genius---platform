# בדיקות דפדפן

הבדיקות האלה מריצות את האתר האמיתי בדפדפן אמיתי (Playwright/Chromium) מול
שרת אמיתי, ובודקות מה שהמשתמש **רואה על המסך** — לא מה שהקוד אמור להחזיר.
הן משלימות את `backend/tests/test_audit.py`, שבודק את הלוגיקה עצמה.

## הרצה

```bash
npm install -g playwright && npx playwright install chromium   # פעם אחת
./browser-tests/run.sh e2e.js        # 76 בדיקות — כל המסכים במחשב
./browser-tests/run.sh mobile.js     # 21 בדיקות — פריסת טלפון ב-375px
./browser-tests/run.sh firstrun.js   # 16 בדיקות — חנות חדשה בלי נתונים
./browser-tests/run.sh degrade.js    # 13 בדיקות — כל מסך מול תשובת שרת ריקה
./browser-tests/run.sh theme.js      # 51 בדיקות — ארבע ערכות הצבע וניגודיות
```

הסקריפט מרים שרת נקי עם מסד נתונים ריק, מגיש עותק זמני של `docs/` שמכוון
ל-`localhost:8080` במקום לשרת החי, ומוריד הכל בסוף. אם פורט 8080 או 8000
תפוס — הוא **מסרב לרוץ**, כדי שלא ייווצר מצב שבו בדיקה עוברת מול שרת ישן
שנשאר מהרצה קודמת. זו הייתה תקלה אמיתית פעם אחת, ולכן ההגנה הזו קיימת.

## מה כל חבילה מכסה

| קובץ | מה נבדק |
|---|---|
| `e2e.js` | סקירה, טרנדים וחגים, חיזוי, כמה להכין, דוח שבועי, מבצעים, ספקים, פורטל ספקים, העברת מלאי, הגדרות, העלאת BKMV ו-CSV בקידוד Windows-1255, קובץ פגום, בקרת גישה, בריחת תווים בצ'אט, PWA |
| `mobile.js` | אין גלישה אופקית, תפריט נפתח ונסגר, טבלאות רחבות גוללות בתוך הקופסה שלהן |
| `firstrun.js` | חנות שנרשמה ועוד לא העלתה קובץ: שאף מסך לא מציג ₪0 כאילו הוא מספר אמיתי, שההודעה בעברית, ושיש כפתור פעולה ולא רק שם של מסך לחפש |
| `degrade.js` | כל 13 המסכים מול שרת שמחזיר `{}` — גרסה ישנה, חדשה, או שדה שפשוט לא קיים. אף מסך לא נופל |
| `theme.js` | ארבע ערכות הצבע: שכל אחת באמת משנה את הדף, נשמרת אחרי רענון, מוחלת **לפני** הציור הראשון, ושכל טקסט גלוי בכל מסך עומד ב-WCAG AA מול הרקע שהוא באמת יושב עליו |

## מגבלות

- Chart.js נטען מ-CDN. בסביבה בלי גישה לאינטרנט הגרפים לא ייטענו, והבדיקות
  מתעלמות משגיאות הרשת האלה במפורש. הן **לא** מתעלמות משגיאות של האתר עצמו.
- הבדיקות רצות מול נתוני דמו. הן מוכיחות שהחישוב והתצוגה עקביים,
  לא שהנתונים נכונים לחנות אמיתית — לזה צריך ייצוא אמיתי מקופה.
